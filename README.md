# Anix Wiki

Рабочая база знаний Anix по онбордингу, продажам, продуктам, производству, кейсам и профессиональной библиотеке.

## Локальный запуск

```bash
npm install
npm run docs:dev
```

Сборка:

```bash
npm run docs:build
npm run docs:preview
```

## Публикация

`main` автоматически собирается и публикуется через GitHub Actions → GitHub Pages. Целевой домен: `wiki.anix-ai.pro`.

## Карта контента

- `docs/onboarding/` — маршрут нового сотрудника;
- `docs/sales/` — рабочая система продаж;
- `docs/products/` — продуктовые карточки;
- `docs/playbooks/` — отраслевые sales playbook’и;
- `docs/production/` — бриф, производство, QC и правки;
- `docs/cases/` — карта доказательств;
- `docs/expertise/` — исследования, источники и словарь;
- `docs/library/` — книги и маршруты чтения.

## Как добавлять знания

- одна рабочая задача или тема — одна страница;
- короткий ответ сверху, детали ниже;
- факт, отзыв и гипотеза маркируются отдельно;
- внешние утверждения получают первичный источник;
- для новых материалов используйте [шаблоны](docs/templates/index.md);
- правки можно предложить прямо через ссылку в wiki.

## Публичность

Репозиторий публичный. `noindex` снижает вероятность индексации, но не является контролем доступа. Не размещайте персональные данные, договоры, внутренние финансы, клиентские материалы под NDA, контакты, ключи и защищённые авторским правом книги.
