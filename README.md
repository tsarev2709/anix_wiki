# Anix Wiki

Внутренняя база знаний Anix по продажам, производству и продуктовой экспертизе.

## Локальный запуск

```bash
npm install
npm run docs:dev
```

Сборка:

```bash
npm run docs:build
npm run docs:preview
```

## Публикация

`main` автоматически собирается и публикуется через GitHub Actions → GitHub Pages.
Целевой домен: `wiki.anix-ai.pro`.

После первого merge нужно один раз открыть **Settings → Pages**:

1. Source: **GitHub Actions**.
2. Custom domain: `wiki.anix-ai.pro`.
3. В DNS создать `CNAME`: `wiki` → `tsarev2709.github.io`.
4. После выпуска сертификата включить **Enforce HTTPS**.

> Важно: репозиторий сейчас публичный, поэтому опубликованная база тоже публично доступна. В конфиге стоит `noindex`, но это не контроль доступа. Для реально закрытой базы нужен отдельный access layer (например, Cloudflare Access) или приватная публикация в GitHub Enterprise Cloud.

## Как добавлять знания

- одна рабочая задача или тема — одна страница;
- короткий ответ сверху, детали ниже;
- используйте ссылки между связанными страницами;
- для новых материалов начните с [шаблонов](docs/templates/index.md);
- правки можно делать прямо через ссылку **«Редактировать эту страницу»** в wiki.
