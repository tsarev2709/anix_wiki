# Как пользоваться Anix Wiki

<span class="anix-kicker">Start here</span>

Wiki строится вокруг рабочих ситуаций, а не вокруг оргструктуры. Сначала ищем ответ через поиск, затем — через раздел.

## Четыре типа страниц

| Тип | Когда открывать | Пример |
|---|---|---|
| **How-to** | нужно сделать действие сейчас | «Как провести КЭВ» |
| **Reference** | нужен точный факт | словарь, цены, договорные условия |
| **Explanation** | нужно понять логику | почему мы продаём переход в новую реальность |
| **Tutorial** | нужно научиться | онбординг нового продавца |

Это разделение помогает не смешивать длинную теорию с инструкцией, которую человек читает прямо перед звонком.

## Правило хорошей страницы

Сверху — ответ и действие. Ниже — аргументация, примеры и детали. В конце — связанные материалы и следующий шаг.
