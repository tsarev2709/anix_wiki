# Как редактировать wiki

## Самый быстрый способ

На любой странице нажать **«Редактировать эту страницу»**. GitHub откроет Markdown-файл.

## Хорошая правка

- отвечает на реальный вопрос;
- ставит короткий ответ выше длинного объяснения;
- использует конкретные заголовки;
- связывает страницу с соседними темами;
- не дублирует уже существующий материал;
- отделяет подтверждённый факт от гипотезы.

## Когда создавать новую страницу

Создавайте, если тема:

- регулярно возникает в продажах или производстве;
- имеет самостоятельный ответ;
- будет полезна больше одного раза;
- раздувает существующую страницу.

## Definition of done для знания

Человек, который не был в исходном разговоре, может открыть страницу и понять, **что делать дальше**.
