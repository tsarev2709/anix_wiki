# Калькуляторы видео, фарма-кампании и HSE

<span class="anix-kicker">Внутренняя пресейл-модель</span>

Три калькулятора помогают за несколько минут собрать диапазон и увидеть, **какие параметры двигают бюджет**. Они не заменяют бриф, производственную оценку и КП.

<QuoteCalculators />

## Что именно считается

| Калькулятор | Основные драйверы | Для какого разговора |
|---|---|---|
| Видео | длительность, сложность, research, адаптации, срок | первый ориентир по отдельному ролику |
| Фарма | master-ролики, claims/MoA, аудитории, cut-down, локализации | кампания по препарату или портфелю |
| HSE | число тем, объект, форматы, языки, общий toolkit | серия или годовая safety-программа |

## Правило диапазона

1. Соберите **базовый** сценарий без необязательных элементов.
2. Соберите **рабочий** сценарий с нужными версиями и согласованиями.
3. Соберите **hero**-сценарий с высоким creative/R&D и кампанией.
4. Объясняйте разницу через scope, а не через скидку.

Ориентир Anix для минуты — широкий диапазон **300 тыс. – 1,5 млн ₽**, потому что минута шаблонной графики и минута с разработкой мира, персонажей, MoA или сложной consistency — разные продукты.

::: warning Не отправлять как готовое КП
Калькулятор не знает реальный объём claims, права, исходники, количество согласующих, технические требования площадок и стоимость критических change request. Цена фиксируется только после квалификации и производственной оценки.
:::

## Что не публикуем в расчёте

- внутреннюю себестоимость и маржу;
- ставки отдельных исполнителей;
- клиентские скидки и договорённости;
- неподтверждённые обещания экономии;
- «цену за нейросеть» без описания результата.
