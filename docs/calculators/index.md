# Калькуляторы цен

Ниже — первая внутренняя модель для быстрой грубой оценки. Она специально прозрачная: все параметры можно менять во время разговора внутри команды.

<PriceCalculator />

## Как использовать

1. Ввести длительность.
2. Проверить актуальную ставку за минуту.
3. Выбрать коэффициент сложности.
4. Добавить фиксированные исследования / разработку / адаптации отдельной суммой.
5. Заложить резерв на неопределённость.

::: warning Не отправлять клиенту как КП
Это инструмент первичной оценки. Коммерческая цена должна учитывать конкретный scope, сроки, риски, количество согласующих, права и экономику проекта.
:::
