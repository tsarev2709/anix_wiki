# Воронка продаж Anix

## Рабочая логика

| Этап | Что должно произойти | Артефакт / доказательство перехода |
|---|---|---|
| Первое касание | клиент увидел релевантность | письмо / КП / презентация / ролик |
| Диалог | есть ответ и ответственный | контакт ЛПР / рабочей группы |
| КЭВ / встреча | выявлены задачи и критерии | заметки + договорённый следующий шаг |
| Дорожная карта | понятен контур решения | короткий план / предложение |
| Договор + ТЗ | юридика и содержание сходятся | согласованные версии документов |
| Предоплата | проект можно запускать | оплата + финальный scope |
| Производство | делаем согласованный результат | промежуточные сдачи |
| Закрытие | результат передан и оплачен | финальные материалы + оплата |
| Повтор | найдена следующая задача | новый scope / контракт |

## Главный принцип

Сделка не должна «висеть в разговоре». У каждого активного клиента есть:

1. текущий этап;
2. конкретный следующий шаг;
3. владелец шага;
4. дата;
5. критерий, после которого двигаем карточку дальше.

## ABCD-фокус

Из конспекта «Гребень Продаж»: максимум внимания отдаём сегменту **A** — есть потребность, деньги и срочность. Сегмент B можно догревать, но он не должен съедать ресурс, который нужен A.

::: tip Практика
Если менеджер не может назвать следующий шаг и дату — сделка не управляется.
:::
