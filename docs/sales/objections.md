# Работа с возражениями

## Сначала определить тип

| Истинное | Ложное / защитное |
|---|---|
| дорого | надо подумать |
| долго | надо посоветоваться |
| есть риск качества | я сам вам напишу |
| не успеете | сейчас не время |

Ложное возражение не надо «побеждать». Нужно спокойно добраться до реального ограничения.

## Алгоритм

1. **Принять формулировку.** Не спорить с первой фразой.
2. **Уточнить.** «Если убрать этот фактор, остальное вас устраивает?»
3. **Диагностировать.** Цена? риск? сроки? внутреннее согласование? отсутствие приоритета?
4. **Ответить доказательством.** Кейс, процесс, цифра, изменение scope.
5. **Проверить.** «Это снимает вопрос?»
6. **Вернуть к следующему шагу.**

## «Дорого»

Не защищать цену абстрактно. Сначала выяснить, **дорого относительно чего**: бюджета, альтернативы, ожидаемого эффекта или другого подрядчика.

## «Пришлите цену» до встречи

Можно дать диапазон или несколько уровней, а затем уточнить, какой контур задачи сравнивает клиент. Цена без контекста должна вести к диалогу, а не заменять его.
