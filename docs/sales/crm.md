# CRM: как ведём карточку клиента

## Минимальный набор данных

### Сделка
- бюджет / диапазон;
- потребность;
- боль / причина действовать;
- срочность;
- источник;
- текущий этап;
- следующий шаг + дата;
- вероятность / качество сделки.

### Контакты
- имя и роль;
- компания;
- телефон;
- email;
- город / часовой пояс;
- ЛПР, влиятель, пользователь или координатор.

## После каждого содержательного касания

Записать:

1. что нового узнали;
2. что обещали мы;
3. что обещал клиент;
4. следующий шаг;
5. дедлайн.

::: tip Золотое правило
Карточка должна быть понятна другому менеджеру без звонка автору.
:::
