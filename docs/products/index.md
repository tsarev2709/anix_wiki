# Линейка продуктов Anix

Рабочая карта. Здесь продукт описывается через **задачу клиента**, а не через внутреннее название услуги.

## 1. Нейроанимация и видеоконтент

Для рекламных, образовательных, продуктовых и корпоративных задач. Форматы: короткие ролики, серии, объясняющая анимация, визуальные концепции.

## 2. Фарма и медицинские коммуникации

Контент для врачей и пациентов: продуктовые ролики, механизмы действия, обучающие материалы, коммуникационные концепции.

## 3. Охрана труда и промышленная безопасность

Короткие обучающие модули, визуализация рисков, onboarding, microlearning и коммуникации по безопасному поведению.

## 4. Корпоративное обучение

Модули, карточки, тесты и интерактивные обучающие сценарии. Может включать LMS / web-слой.

## 5. Корпоративные коммуникации

Онбординг, внутренние кампании, объяснение изменений, HR- и employer-branding контент.
