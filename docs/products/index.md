## Три масштаба покупки

| Масштаб | Что покупает клиент | Когда предлагать |
|---|---|---|
| Pilot | одна ситуация, один master, 1–3 версии | первый совместный проект |
| System | серия + visual bible + asset library | ценность первого решения доказана |
| Program | квартальный/годовой план, производство и измерение | есть регулярный владелец, бюджет и контент-календарь |

## Общая формула ценности

**Сложная или рискованная тема → ясная визуальная модель → единое объяснение → измеримый следующий шаг.**

## Что может быть первым продуктом

- один master-ролик;
- ограниченная серия по двум продуктам;
- пакет для конференции: master + короткие версии;
- модуль по одной группе рисков;
- sales asset под конкретный клинический сценарий;
- маскот и первая серия материалов;
- прототип сложной сцены или механизма до полного производства.

## Что обычно становится продолжением

**Один материал → адаптации → серия → визуальная система → библиотека активов → квартальная или годовая программа.**

::: warning Не начинать с максимального scope
Первый проект должен быть ограничен, понятен и проверять ценность. Большая платформа, десятки объектов или «весь маркетинг» без общего опыта резко увеличивают риск для обеих сторон.
:::
