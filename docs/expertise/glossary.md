# Словарь

Рабочий словарь пополняется из звонков, ТЗ и отраслевой речи клиентов.

## Продажи

**ЛПР** — лицо, принимающее решение.  
**КЭВ** — ключевой этап воронки / ключевая встреча.  
**Discovery** — этап выявления задачи, боли, критериев и процесса решения.  
**Next step** — конкретное действие с владельцем и датой.

## Производство

**Packshot** — финальный продуктовый кадр / демонстрация упаковки или продукта.  
**Storyboard / раскадровка** — последовательность ключевых кадров до производства финальной анимации.  
**Экспликация** — режиссёрское описание логики, визуального языка и исполнения.  
**Итерация** — один цикл правок по согласованному объёму комментариев.

## AI / нейропроизводство

**Prompt** — инструкция модели для генерации.  
**Consistency** — сохранение внешности персонажей, объектов и стиля между кадрами.  
**Upscale** — увеличение разрешения / детализации финального материала.
