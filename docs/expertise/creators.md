# Блогеры, авторы и эксперты

Для каждой продуктовой вертикали держим **5–10 источников**, которые помогают слышать язык рынка.

## Карточка эксперта

- Имя / канал.
- Ниша.
- Почему следим.
- 3 ключевые идеи.
- Ссылка.
- Что можно использовать в продажах.

## Категории

- AI video / generative media;
- фарма и медицинский маркетинг;
- охрана труда / HSE;
- L&D / корпоративное обучение;
- B2B-продажи и procurement;
- бренд-контент и корпоративные коммуникации.
