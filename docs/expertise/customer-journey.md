# Путь клиента

Клиент покупает не тогда, когда впервые видит красивый ролик. Покупка возникает, когда задача, событие, доверие, бюджет и безопасный первый шаг сходятся в одной точке.

## Общая B2B-модель

| Стадия | Что происходит | Задача Anix |
|---|---|---|
| 1. Фон | проблема ещё не названа | дать язык и пример ситуации |
| 2. Триггер | появляется запуск, риск, событие | показать релевантность |
| 3. Подход | сравнивают форматы решения | помочь выбрать правильный тип продукта |
| 4. Long list | проверяют fit и диапазон | дать кейс и короткую квалификацию |
| 5. Short list | сравнивают риски | показать процесс, команду, границы |
| 6. Согласование | бюджет, legal, medical, ИБ | сделать scope и роли прозрачными |
| 7. Первый проект | проверяют в деле | ограничить риск и дать управляемый результат |
| 8. Масштабирование | ищут повторяемость | активы, серия, другие каналы / объекты |

## Разные триггеры по вертикалям

| Фарма | HSE | MedTech | Сложный B2B |
|---|---|---|---|
| запуск препарата | выход подрядчиков | конференция | важная выставка |
| цикл кампании | остановочный ремонт | новый релиз | новый сегмент |
| HCP-мероприятие | повторное нарушение | подготовка пилота | слабый outreach |
| задача по портфелю | новый объект | зависшая сделка | основатель — единственный demo |

## Что переводит дальше

- релевантный кейс;
- точная гипотеза проблемы;
- понятный первый scope;
- карта согласований;
- ранний прототип;
- доказательство содержательной компетенции;
- прозрачные критерии приёмки;
- договорённый следующий шаг.

## Что тормозит

- интерес без события;
- контакт без полномочий;
- слишком большой первый проект;
- неподтверждённое обещание результата;
- бесплатная глубокая разработка;
- неизвестные согласующие;
- материал «для всех каналов и аудиторий»;
- отсутствие внутреннего владельца после сдачи.

## Практика продавца

Перед каждым касанием ответьте:

1. На какой стадии клиент?
2. Какой риск он пытается снять?
3. Какое доказательство ему нужно сейчас?
4. Что будет преждевременно?
5. Какой новый факт переведёт сделку на следующую стадию?
