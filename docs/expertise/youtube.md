# YouTube: учебный маршрут

Цель — не смотреть индустриальный контент бесконечно. После каждого блока должен появиться рабочий артефакт.

## Трек 1. Визуальный язык

- [Ben Marriott](https://www.youtube.com/@BenMarriott) — выбрать один разбор и выписать три решения по ритму, форме или переходам.
- [Corridor Crew](https://www.youtube.com/@CorridorCrew) — найти один AI/VFX-разбор и разделить «эффектно» от «надёжно в клиентском производстве».
- [School of Motion](https://www.youtube.com/@schoolofmotion) — выбрать разбор production pipeline или профессии.

**Результат:** короткая заметка «что переносим в Anix / что не переносим».

## Трек 2. Продажа креативной работы

- [The Futur](https://www.youtube.com/@thefutur) — смотреть разборы client discovery, value и pricing критически, адаптируя к российскому B2B.
- публичные выступления реальных ЛПР клиента — важнее общих sales-блогеров.

**Результат:** три формулировки вопросов для следующей КЭВ.

## Трек 3. Язык отрасли

Для каждой активной вертикали раз в месяц найти:

1. одно выступление ЛПР;
2. один разбор реального кейса;
3. один разговор о закупке / внедрении;
4. один технический материал;
5. один критический взгляд на модный подход.

**Результат:** обновить playbook, а не просто оставить ссылку в чате.

## Карточка видео

```md
## Название / автор / дата
- Ссылка:
- Главный тезис:
- Что подтверждено:
- С чем спорим:
- Как применить в продаже / производстве:
- Какую страницу wiki обновить:
```
