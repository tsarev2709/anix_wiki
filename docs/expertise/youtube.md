# YouTube: обязательный просмотр

Цель страницы — не каталог ссылок, а **короткий учебный плейлист продавца**.

## Как собирать

Для каждой продуктовой вертикали выбрать:

1. 2–3 видео «как устроен рынок»;
2. 2–3 видео по производству;
3. 2–3 сильных кейса;
4. 1–2 разборa экономики / закупки;
5. 1–2 видео с речью самих клиентов.

## Очередь на заполнение

- нейроанимация и AI video;
- фарма-коммуникации;
- охрана труда и промышленная безопасность;
- корпоративное обучение / LMS;
- корпоративные коммуникации и HR.

> Для каждой ссылки обязательно записывать: **что именно продавец должен из неё вынести**.
