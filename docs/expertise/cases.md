# Топ-10 кейсов для экспертности

Сюда входят **свои и чужие** кейсы. Цель — уметь быстро показать рынок возможностей и аналогии для клиента.

## Структура карточки кейса

1. Компания / отрасль.
2. Исходная проблема.
3. Решение.
4. Почему решение сработало.
5. Результат / метрика.
6. Что можно перенести в Anix.
7. Ссылка на источник / материалы.

## Отбор

Кейс сильный, если он помогает ответить хотя бы на один вопрос клиента:

- «это вообще работает?»;
- «кто уже так делал?»;
- «что будет с качеством?»;
- «как это внедряется?»;
- «почему столько стоит?».
