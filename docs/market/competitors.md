# Конкуренты и альтернативы

Конкурент — не только другая студия. Часто Anix конкурирует с другим способом решить задачу.

## Категории

1. Классические animation / production studios.
2. AI-native студии.
3. Рекламные и креативные агентства.
4. L&D / LMS-подрядчики.
5. Внутренний отдел клиента.
6. Фриланс-команда.
7. «Не делать проект вообще».

## Карточка конкурента

| Поле | Что фиксируем |
|---|---|
| Сегмент | где пересекаемся |
| Сильные стороны | почему их выбирают |
| Слабые стороны | где клиент рискует |
| Цена / модель | если подтверждено |
| Скорость | если подтверждено |
| Кейсы | на что ссылаются |
| Наше отличие | без карикатуры на конкурента |

## Главное

Сравнивать надо по **критериям покупки клиента**, а не по списку функций.
