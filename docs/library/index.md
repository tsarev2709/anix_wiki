## Как хранить файлы

Репозиторий публичный. Здесь можно размещать:

- собственные конспекты;
- книги и отчёты с открытой лицензией;
- официально распространяемые материалы;
- ссылки на приобретённые командой экземпляры в закрытом хранилище.

Нельзя загружать пиратские PDF, клиентские документы, файлы под NDA и персональные данные.

## Статусы чтения

| Статус | Значение |
|---|---|
| База | нужно большинству команды |
| По роли | обязательно конкретной функции |
| Углубление | читать под задачу |
| Справочник | не читать подряд, открывать по вопросу |
