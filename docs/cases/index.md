# Кейсы Anix

Здесь будет единая библиотека кейсов, заточенная под продажи.

## У каждой карточки кейса должно быть

- клиент / отрасль;
- задача;
- решение;
- что было сложно;
- как решили;
- результат;
- визуальные материалы;
- какие возражения этот кейс снимает;
- для каких клиентов показывать.

**Фарма · Охрана труда · Корпоративное обучение · Реклама · Корпоративные коммуникации · AI-production**
